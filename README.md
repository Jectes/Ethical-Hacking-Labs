## 📖 About This Repository

Welcome to **ZeroDay Tech Labs**, a collection of practical cybersecurity projects conducted in controlled lab environments.

Each project explores a different security risk, documenting the simulation, observed evidence, potential real-world impact, and recommended defensive measures.

### 🔬 Research Areas

- Social engineering and credential exposure
- Android application security and sideloading risks
- Browser permissions and location privacy
- Threat analysis and security awareness
- Defensive mitigation and prevention

These projects are intended for cybersecurity education, defensive research, and security awareness. No unauthorized access to third-party systems was involved.
